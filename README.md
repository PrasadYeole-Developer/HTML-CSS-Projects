# HTML & CSS Projects  

A collection of web projects built using **HTML** and **CSS**. These projects focus on fundamental structure, styling, and layout techniques.  

## 🚀 Features  
- Static web designs with clean and structured code  
- CSS styling with a focus on visual aesthetics  

## 📂 Projects Included  
### Landing Page  
A modern landing page featuring a minimalist design, bold typography, and layered images. Built with **HTML, CSS, and Remix Icons**, it offers a sleek and user-friendly experience.  

### Sample Portfolio  
A professional portfolio website for a content creator, showcasing expertise in **digital design, interaction design, motion design, and art direction**. Uses **HTML, CSS, and Remix Icons**, with a modern layout, smooth navigation, and engaging visuals.  

### Portfolio Website  
A clean and modern portfolio website that highlights projects and expertise in **digital design**. Built with **HTML, CSS, and Remix Icons**, offering a simple yet professional look.  

### Blog Website  
A minimal and well-structured blog page featuring clean typography, intuitive navigation, and stylish content sections. Uses **HTML & CSS**, incorporating a **responsive layout** and interactive elements for readability.  

### Coffee Shop  
A structured **two-column** coffee shop website with a **navigation bar, sidebar links, featured coffee varieties**, and high-quality images. Styled using **Flexbox** for better responsiveness.
